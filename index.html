Atalhos

        
      

      

        

          
            

              Ctrl + Enter
              Formatar JSON/XML (ou Comparar no Diff)
            

            

              Ctrl + M
              Minificar JSON/XML
            

            

              Ctrl + T
              Árvore JSON/XML
            

            

              Ctrl + D
              Ligar / desligar Diff
            

            

              Ctrl + Shift + Enter
              Comparar (no Diff)
            

            

              Ctrl + H
              Histórico
            

            

              Ctrl + Shift + C
              Copiar saída
            

            

              Ctrl + L
              Limpar
            

            

              ? ou Ctrl + /
              Abrir esta ajuda
            

            

              Esc
              Fechar modal
            

          
        

        

          Format, Minify e Tree aceitam JSON e XML. O Diff compara JSON, XML ou
          texto livre.
        

        
No Mac, use ⌘ no lugar de Ctrl.
